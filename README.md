# Laravel Model Preferences

Laravel Model Preferences stores per-model preferences, such as themes, notification options, or
feature toggles, with defaults, validation, casts, eager loading, and query scopes.

```bash
composer require hosmelq/laravel-model-preferences

php artisan model-preferences:install
```

Read the [full documentation](https://hosmelq.com/docs/laravel-model-preferences).

## Development

Run the test suite with:

```bash
composer test
```
